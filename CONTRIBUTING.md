# Contributing

Thank you for your interest in contributing!

## Getting started

```bash
npm install
npm run dev
```

## Guidelines

- Keep it dependency-free — this project intentionally uses no runtime libraries
- Match the existing code style (vanilla JS, CSS custom properties)
- Test in both light and dark themes before submitting

## Reporting issues

Please open a GitHub issue with:
- A clear description of the problem
- Steps to reproduce
- Browser and OS version
